UAE4ALL2 HD Switch – Game Cover Art Directory
=============================================

Place cover images here using the EXACT game name as the filename:

  SWIV.png
  Turrican.jpg
  Speedball2.png
  ...

File naming rules:
  - Use the game name WITHOUT the file extension
    (e.g. "SWIV" for "SWIV.adf", "Turrican" for "Turrican.lha")
  - For WHDLoad games, use the WHDLoad folder name
  - Strip any trailing tags: "(AGA)", "[!]", "(Demo)" are handled automatically
  - Case is preserved on Linux/Switch SD card – prefer exact match

Supported formats:  .png  .jpg  .jpeg
Recommended size:   300×400px or similar portrait aspect ratio (2:3)
Maximum safe size:  1280×1024px  (larger images are scaled in software)

Cover search order:
  1. ./data/covers/<name>.png
  2. ./data/covers/<name>.jpg
  3. ./data/covers/<name>.jpeg
  4. ./roms/covers/<name>.png
  5. ./roms/covers/<name>.jpg
  6. <directory of game file>/<name>.png
  7. <directory of game file>/<name>.jpg
